# Evidence Checklist

Before approving a UI, confirm you captured enough evidence:

- Route or entrypoint identified
- App health confirmed
- Required viewports checked
- At least one screenshot or snapshot per important state
- Console checked
- Network checked when relevant
- Geometry measured for suspicious layout groups
- Accessibility checked when relevant
- Findings mapped to severity
- Recommended regression tests proposed

If any of the above is missing, explain why.
