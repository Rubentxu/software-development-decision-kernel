# Taxonomía de ejercicios

Basada en Bloom, adaptada a libros técnicos.

## Recordar / Aplicar
Uso directo del concepto recién aprendido.
- "Escribe un sistema que incremente un contador en cada frame."
- Verifica que el lector sabe reproducir el patrón base.

## Analizar
Diagnosticar o explicar un fragmento dado.
- "Este código compila pero corre secuencialmente. ¿Por qué?"
- Verifica comprensión profunda, no solo copia.

## Crear
Construir algo que combina varios conceptos.
- "Añade un segundo sistema que lea el contador y lo imprima cada N frames, asegurando paralelismo."
- Verifica integración de múltiples ideas del capítulo.

## Reglas de diseño
- Dificultad creciente dentro del capítulo.
- Nunca un ejercicio que requiera un concepto no introducido.
- Pistas graduadas: conceptual → operativa → casi-solución.
- Criterios de evaluación observables (no "entender bien", sino "identifica X").
