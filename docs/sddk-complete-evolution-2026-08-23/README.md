This ZIP contains the **complete proposal history** plus the consolidated current target.

- `CURRENT/` — recommended integrated proposal.
- `HISTORY/` — earlier proposal generations preserved unchanged where available.

The CURRENT proposal includes:

1. Engineering Assurance.
2. Netstack3-derived systems reasoning.
3. Governed Continuous Improvement.
4. Autoresearch ideas that fit SDDK, with unrelated ideas explicitly rejected/deferred.
5. Agent-First Goal-Oriented Deterministic Interface.
6. Full reporting/evidence compatibility so fewer LLM/CLI calls do **not** mean less functionality.
7. Roadmap, ADRs, specs, fitness functions, migration, testing, research synthesis and skills.
