# Workbook — Object-Oriented / SOLID / GRASP Lens

SOLID and GRASP are lens heuristics, not universal laws. Table uses categorical state + evidence, not one numeric score.

Inputs may include change reasons, interfaces, fan-out, implementations, subtype tests and responsibility clusters.

A concern conflicting with an accepted tradeoff is shown as ACCEPTED/REVIEW_DUE rather than imperative refactor advice.
