# Assessment lifecycle

```text
Evidence
 -> Observation
 -> Assertion
 -> Assessment
 -> Tension/Opportunity/ContractViolation
 -> optional Governance policy
```

Assessments are temporal and basis-bound. When inputs change they become INVALIDATED/POSSIBLY_STALE until reevaluated.

If a tradeoff covers a tension:

`TENSION -> ACCEPTED`.

If its revisit trigger fires:

`ACCEPTED -> REVIEW_DUE`.

Nothing automatically becomes a refactoring task unless Planning/Governance creates one.
