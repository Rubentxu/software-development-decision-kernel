# v1.66.6 — 2026-09-02

## Summary

v1.66.6 is a PATCH release that closes 11 gaps from cycle-51 and promotes
`cycle supersede` to behaviorally-and-documentationally-first-class: 3 engine bugs
(GAP-BUG-1/2/3), 3 engine/CLI validations (GAP-V-1/2/3), 1 UX fix (GAP-UX-1),
and 4 docs promotions (GAP-DOC-1.a/b/c/d).

## Gaps Closed

### Engine bugs

- **GAP-BUG-1**: `cycle_supersede` ahora libera el lease atómicamente en la
  misma transacción que `cycle.supersede.applied` (antes: `release_lease_on_phase_change=false`).
- **GAP-BUG-2**: `supersede-receipt.json` ahora escribe `lease_owner` desde el
  argumento `lease_owner` del caller (antes: usaba `actor`).
- **GAP-BUG-3**: `supersede-receipt.json` ahora escribe `fencing_token` desde el
  argumento `fencing_token` del caller (antes: hardcodeado a `0`).

### Engine / CLI validations

- **GAP-V-1**: CLI ahora declara `#[arg(conflicts_with)]` en `--successor` para que
  clap rechace la combinación `--successor` + `--reason` en parse-time.
- **GAP-V-2**: Engine ahora rechaza `--successor nonexistent-cycle` antes de
  cualquier mutación de estado (usa `Storage::cycle_exists`, patrón
  INC-DEBT-017).
- **GAP-V-3**: Engine ahora rechaza `--evidence-refs "[]"` vacío antes de
  cualquier mutación (SPEC §2 línea 87: MUST).

### UX fix

- **GAP-UX-1**: `cycle supersede` ahora llama `validate_cycle_project` antes
  de cualquier acceso a storage, convirtiendo `STORAGE_NOT_FOUND` para bare
  slugs en un error tipado apuntando a la forma canónica
  `<project_id>/<slug>`.

### Docs promotions

- **GAP-DOC-1.a**: `ADR-0079-cycle-supersede.md` flip status → `accepted`.
- **GAP-DOC-1.b**: `SPEC-SUPERSEDE-001.md` promovido a
  `docs/sddk-decision-kernel-architecture/04-specs/`.
- **GAP-DOC-1.c**: `AGENTS.md` §9 cycle supersede workflow añadido.
- **GAP-DOC-1.d**: `docs/releases/v1.66.6.md` release notes.
