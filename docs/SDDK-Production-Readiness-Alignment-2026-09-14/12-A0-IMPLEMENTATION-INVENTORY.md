## Selection

First unresolved MUST by dependency/risk order: **PR-GAP-005** (single migration owner).

Rationale:
- concrete, spec-backed (`arch-spec-020` SSO-001), bounded to storage;
- behavior-preserving under the production open order, and removes a real latent divergence (`MIGRATION_1` full `projects` table vs `MIGRATION_5` minimal stub, both `CREATE TABLE IF NOT EXISTS` on the same `ledger.sqlite`);
- no product/authority decision required, unlike PR-GAP-006/007;
- unblocks later A0 work (PR-GAP-004 classification and PR-GAP-008/009) without coupling semantics to physical moves.

PR-GAP-006 (High-band enforcement flip) is deliberately **not** first: it is a production behavior change that needs the approval loop confirmed live and a rollback plan — it will be escalated with bounded options before implementation.
