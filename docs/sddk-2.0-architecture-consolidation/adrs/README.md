# ADR Index

All ADRs are **Proposed** for the SDDK 2.0 consolidation cycle unless explicitly accepted in the repository later.

1. Event ledger as operational authority
2. Graph is a projection, not a source of truth
3. Workflow authority remains separate from reactive graph behaviors
4. Enforce hexagonal boundaries structurally
5. Extract UAT as bounded context/pack
6. Make packs the primary extension model
7. Keep a minimal universal core vocabulary
8. Behaviors and agents propose; capabilities perform effects
9. Evidence becomes a platform primitive
10. Add fork/replay/diff/promote
11. Abstract GraphStore; start lightweight/local
12. Introduce Behavioral IR and content-bound agent identity
13. Add context-read tracing
14. Add signed local gate receipts with remote verification
15. Introduce release channels
16. Outcomes-as-events, misuse-as-errors
17. Moldable views over one graph/ledger
18. Split stable documentation from history and ephemeral handoff
