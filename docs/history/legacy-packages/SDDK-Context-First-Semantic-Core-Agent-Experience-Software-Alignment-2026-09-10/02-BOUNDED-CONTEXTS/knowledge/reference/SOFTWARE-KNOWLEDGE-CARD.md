# Software Knowledge Card

```text
identity / role / purpose
responsibilities
bounded context
architectural role
dependencies / effects / ports/adapters
active assessments by focus
invariants/tradeoffs/decisions
findings/debt/unknowns
freshness/coverage/evidence diversity
```

Card output should be bounded (top findings/dependencies/tradeoffs) and link to workbook/detail queries.
