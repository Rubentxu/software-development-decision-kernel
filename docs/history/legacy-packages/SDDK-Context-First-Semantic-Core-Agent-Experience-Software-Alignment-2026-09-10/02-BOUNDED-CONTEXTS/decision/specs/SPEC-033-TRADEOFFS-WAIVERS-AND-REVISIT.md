# SPEC-033 — Tradeoffs, Waivers and Revisit

Canonical tradeoffs remain in Decision Memory:

```text
scope
forces
alternatives
chosen_option
benefits/costs/risks
assumptions
accepted_debt
revisit_when
expires_when?
owner
```

Alignment projects a Decision Balance Sheet and marks `REVIEW_DUE` when assumptions/triggers drift.

Waivers are governance objects/facts with reason, DecisionRef, owner and expiry/revisit. Alignment can report an expired waiver but does not approve one.
