# Ubiquitous Language

| Term | Meaning |
|---|---|
| Concern | paradigm-neutral property worth observing |
| Lens | optional interpretation heuristic for a paradigm/architecture/ecosystem |
| Intent | declared/decided expectations against which observations may be compared |
| Observation | evidence-backed statement about software |
| Assessment | interpretation of observations under intent/lens |
| Tension | discrepancy worth attention that may still be intentional |
| Misalignment | strong evidence that observed state diverges from intent/lens |
| ContractViolation | divergence from explicit MUST/forbidden contract |
| Opportunity | non-imperative possible improvement with tradeoffs |
| Accepted | tension covered by an active decision/tradeoff/waiver |
| ReviewDue | accepted rationale whose assumptions may no longer hold |
| KnowledgeDebt | missing/stale/contradictory understanding |
| AttentionPriority | ranking of where deeper inspection may have value |

Avoid generic `violation` for heuristic design opinions.
