# Workbook control mechanisms

Mechanisms available to downstream governance/read models:

- ratchet (do not worsen baseline);
- budget (bounded tolerated count/value);
- waiver with expiry/revisit;
- watchlist;
- invariant verification;
- contradiction alert;
- decision revisit trigger;
- attention ranking;
- evidence coverage target.

Alignment computes observations and state. Governance decides whether a control blocks.
