# Workbook model

A Workbook is a focus-specific spreadsheet/dashboard projection over the same knowledge substrate.

Common sections:

`overview, inventory, assessments, findings, metrics, trends, tradeoffs, invariants, contradictions, stale, hotspots, charts`.

Every row must be traceable to assertions/evidence/decisions. Charts are derived from table series. Workbooks support filtering by scope, basis, status, lens and time.
