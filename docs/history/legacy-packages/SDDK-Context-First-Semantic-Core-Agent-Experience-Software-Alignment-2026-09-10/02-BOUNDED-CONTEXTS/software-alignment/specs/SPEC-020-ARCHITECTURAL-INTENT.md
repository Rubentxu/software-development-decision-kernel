# SPEC-020 — Architectural Intent

`ArchitecturalIntent` is a compiled read model assembled from:

- declared module/context roles;
- explicit dependency constraints;
- invariants;
- Decision Memory;
- tradeoffs and waivers;
- selected paradigm lenses;
- project configuration.

It is not a new document authority.

## Expected vs Observed

Alignment compares typed observations to intent and records proof links.

## Precedence

Explicit project decisions/contracts override generic lens heuristics. A lens can flag a tension against an accepted decision, but must surface the accepted tradeoff instead of presenting it as a required fix.
