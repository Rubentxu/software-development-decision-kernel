# Deferred ideas and revisit triggers

These are intentionally outside the consolidation critical path.

| Idea | Deferred because | Revisit when |
|---|---|---|
| external graph DB | local projection sufficient | measured graph size/query latency breaches SLO |
| vector database | exact/FTS/graph retrieval should be evaluated first | recovery benchmark shows material recall gap |
| remote/distributed memory service | local-first kernel priority | multi-user/shared control-plane requirement is real |
| general agent marketplace | pack SDK needs real second/third-party use first | ≥3 independent packs exist |
| advanced graphical IDE | presentation is not kernel responsibility | separate product has validated users |
| full Git-compatible memory protocol | needless complexity | interoperability demand exists |
| automatic semantic merge by LLM | authority/risk unclear | deterministic conflict model proves insufficient |
| cross-project global decision memory | privacy/scope complexity | explicit organizational use case appears |
