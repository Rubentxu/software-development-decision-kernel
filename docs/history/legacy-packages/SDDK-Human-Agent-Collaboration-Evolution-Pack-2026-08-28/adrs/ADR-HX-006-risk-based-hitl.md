# ADR-HX-006 — Risk-Based HITL

**Status:** proposed  
**Date:** 2026-08-28

## Context
Interactive vs auto confunde informar con aprobar.

## Decision
Usar guided/balanced/autopilot sobre una policy de risk/reversibility/authority. Hard approvals nunca se bypass.

## Consequences
Menos interrupciones y mejor auditabilidad.

## Alternatives considered
Pause-after-every-phase y fully-auto sin gates rechazados.
