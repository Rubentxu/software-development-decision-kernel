  unreachable, accepted risk).

## 8. Risks

- **R1**: `time` 0.3.47 may have API drift from 0.3.36. Mitigated: usage is limited
  to `OffsetDateTime::now_utc()`, `.format()`, `.unix_timestamp()` — all stable APIs.
- **R2**: `cargo update` may unintentionally bump other unrelated dependencies.
  Mitigated: use `-p quinn-proto --precise 0.11.15` for targeted update if available;
  if not, use `cargo update` and review the diff before commit.
- **R3**: `cargo-audit` may report new vulns introduced by the upgrade (e.g. if
  0.3.47 has its own issue). Mitigated: T6 re-audit will catch this; if new
  vuln appears, document and decide whether to revert.
