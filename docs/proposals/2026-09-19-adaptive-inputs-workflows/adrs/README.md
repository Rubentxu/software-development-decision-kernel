# ADR candidatas — NO promocionadas

Estas ADR son **propuestas internas del paquete**, con IDs locales `AIW-ADR-*` para evitar colisiones con el registro canónico de `docs/architecture/adrs/` (último observado ADR-0137). No copiar a la numeración canónica ni cambiar `status` hasta pasar ADR-0001, reconciliar el roadmap y asignar un número libre en el checkout de integración. Una ADR aceptada documenta una decisión, **no** certifica la implementación.
