# arch-spec-040 — Architecture Conformance Workbooks

## Intent

Authority, ownership, compatibility, paradigm topology and drift views SHALL be rebuildable workbooks over semantic graph/evidence, never canonical truth.

## Requirements

- AC-040-001: provide authority/ownership/compatibility/conformance-vector views.
- AC-040-002: every displayed finding links to evidence and contract/decision provenance.
- AC-040-003: workbooks cannot write canonical event/decision/knowledge truth.
- AC-040-004: no universal architecture quality score; expose vector dimensions and statuses.
- AC-040-005: architecture time-travel/diff may compare revisioned bases once history support is stable.
- AC-040-006: behavior maps are generated from event/graph semantics rather than handwritten competing truth.

## Acceptance

AC-UAT-002, 041, 043.
