# UAT Scenarios

## UAT-01 Happy path A-full
Esperado: breadcrumb y next action claros.

## UAT-02 Long apply
Progreso significativo sin tool-call spam.

## UAT-03 Noteworthy finding
Se explica impacto y si cambia plan.

## UAT-04 Resume cold start
Usuario entiende estado con <=150 palabras.

## UAT-05 Reframe
Original/evidence/new direction/impact visibles.

## UAT-06 `/why`
Respuesta basada en decision records, no razonamiento interno.

## UAT-07 Assumption invalidated
Se muestra qué hipótesis cayó y efecto.

## UAT-08 Balanced reversible decision
Continúa y reporta; no pregunta innecesariamente.

## UAT-09 Scope change
Pregunta con opciones y recomendación.

## UAT-10 Destructive/security
Humor suprimido y approval obligatorio.

## UAT-11 Novice
Comprende sin conocer terminología SDDK.

## UAT-12 Expert
No considera la salida verbosa.

## UAT-13 wisecracking_robot
Humor útil, facts intactos.

## UAT-14 Memory learning
Una observación no se promociona; repetición sí.

## UAT-15 Memory correction
edit/forget/pin funcionan.

## UAT-16 Missing cycle id
No inventa current cycle.

## UAT-17 Verify fail
Failure es headline; recovery exacta.

## UAT-18 UAT Human Review
Decision protocol reutilizado por review queue.

## UAT-19 Facade parity
Mismo outcome/artifacts/receipts que low-level.

## UAT-20 Persona mute
Frustración explícita reduce humor inmediatamente.
