# SPEC-010 — Friction Telemetry & F3

## Signals
where_am_i, why_action, confusion, repeated_question, challenge, unnecessary_approval, report_expand, report_collapse, persona_mute, memory_correction.

## Metrics
per-cycle and cross-project.

## F3
May recommend:
- verbosity;
- report timing;
- default disclosure;
- attention thresholds within non-safety band.

May not mutate:
- security/safety policies;
- evidence;
- approval required for high-risk;
- lifecycle gates.
