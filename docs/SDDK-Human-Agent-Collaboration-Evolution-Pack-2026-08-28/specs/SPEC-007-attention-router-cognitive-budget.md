# SPEC-007 — Attention Router

## Levels
silent | phase_summary | noteworthy | decision | critical.

## Rules
- routine tool/test pass -> silent;
- phase boundary -> phase_summary;
- material discovery -> noteworthy;
- human authority -> decision;
- security/data-loss/destructive -> critical.

## Narration budget
progress event <=8 líneas;
phase completion <=140 palabras;
decision <=3 opciones primarias;
evidence collapsed by default.
