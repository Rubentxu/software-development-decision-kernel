# SPEC-003 — StageReport / Never Lost

Cada reporte responde como máximo a siete preguntas:
1. ¿Qué intentábamos conseguir?
2. ¿Qué terminamos?
3. ¿Qué descubrimos?
4. ¿Qué problemas aparecieron?
5. ¿Qué decisiones/reframes ocurrieron?
6. ¿Qué queda?
7. ¿Necesitamos al humano?

## Breadcrumb
`SDDK · <cycle> · <path> · <phase> <progress> · <attention>`

## Novice default
Plain language, jargon explicado, <=140 palabras por phase completion salvo critical/decision.

## Acceptance
UAT comprehension >=90%.
