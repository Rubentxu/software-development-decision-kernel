# SPEC-011 — Human Decision Protocol

## DecisionRequired UX
- concise problem;
- impact;
- <=3 primary options;
- recommendation;
- safe default if one exists;
- reversibility;
- evidence link;
- exact scope affected.

## Policy
guided: ask on medium+;
balanced: ask on high/irreversible/scope/authority;
autopilot: same hard requirements, report medium asynchronously/non-blocking.

Autonomy never bypasses mandatory human authority.
